# VIP to DUT Signal Connectivity Specification

**Project:** RISC-V SoC with DMA, AES-128, and FFT Hardware Accelerators  
**Verification Environment:** SoC UVM VIP Verification Suite  
**Location:** `tb/uvm_soc/`  
**Target DUT:** `main_top.v` (Top-level integrated SoC)  

---

## 1. Overview

This document specifies the exact pin-level connections and signal mapping between the integrated SoC design (`main_top.v`) and the three dedicated UVM Verification IP (VIP) components:
- **GPIO UVM VIP** (`gpio_if`)
- **UART UVM VIP** (`uart_if`)
- **PWM UVM VIP** (`pwm_if`)

In addition, it details the control and memory infrastructure interfaces:
- **SoC Control Interface BFM** (`soc_ctrl_if`) connected to Interconnect Master 1 (`s01_axi`)
- **AXI4 Dual-Port RAM Slaves** (`axi_ram_slave`) connected to Interconnect Slaves 0 (`m00_axi`, IMEM) and 1 (`m01_axi`, DMEM)

---

## 2. GPIO VIP Connectivity Mapping

The GPIO peripheral is mapped to AXI slave index S2 (`0x8000_1000 - 0x8000_1FFF`). The external I/O bus is a 32-bit bidirectional tri-state bus (`gpio_io[31:0]`) with an active-high interrupt line (`gpio_irq`).

### 2.1 Interface Signal Map (`gpio_if`)

| DUT Port (`main_top.v`) | VIP Interface Signal (`gpio_if`) | Signal Direction (DUT perspective) | Width | VIP Role | Verification Function |
| :--- | :--- | :--- | :---: | :--- | :--- |
| `gpio_io[31:0]` | `u_gpio_if.gpio_io[31:0]` | Inout (Bidirectional) | 32 | Tri-state Driver / Passive Monitor | Drives external stimulus when pin is configured as input (`GPIO_DIR[i]=0`). Monitors and samples pin state when configured as output (`GPIO_DIR[i]=1`). |
| `gpio_irq` | `u_gpio_if.gpio_irq` | Output | 1 | Passive Monitor | Captures interrupt assertion on edge/level transitions. |
| `clk` | `u_gpio_if.clk` | Input | 1 | Clock Reference | Synchronous 100 MHz AXI clock. |
| `~rst` | `u_gpio_if.rst_n` | Input | 1 | Reset Reference | Active-low synchronous reset. |

### 2.2 GPIO VIP Internal BFM Wires

| Internal Signal | Direction (VIP perspective) | Width | Description |
| :--- | :---: | :---: | :--- |
| `gpio_in[31:0]` | Output (Driver to Bus) | 32 | Value driven when `gpio_oe[i] == 1'b1`. |
| `gpio_oe[31:0]` | Output (Driver to Bus) | 32 | Output enable mask: `1'b1` = drive `gpio_in[i]`; `1'b0` = release pin to high-Z (`1'bz`). |
| `gpio_out[31:0]` | Input (Bus to Monitor) | 32 | Continuous sampling of `gpio_io` bus levels for scoreboard checking. |

## 3. UART VIP Connectivity Mapping

The 16550-compatible UART controller is mapped to AXI slave index S4 (`0x8000_3000 - 0x8000_3FFF`). It features an independent 40 MHz clock domain (`fixed_clk`) for high-precision baud rate generation (115200 Baud with divisor = 347 cycles).

### 3.1 Interface Signal Map (`uart_if`)

| DUT Port (`main_top.v`) | VIP Interface Signal (`uart_if`) | Signal Direction (DUT perspective) | Width | VIP Role | Verification Function |
| :--- | :--- | :--- | :---: | :--- | :--- |
| `uart_rx` | `u_uart_if.uart_rx_i` | Input | 1 | Active Serial Driver | VIP Driver injects standard 8-N-1 asynchronous serial frames into DUT RX receiver. |
| `uart_tx` | `u_uart_if.uart_tx_o` | Output | 1 | Passive Serial Monitor | VIP Monitor decodes transmitted serial frames, detects start/stop bit alignment, and checks payload integrity in `uart_scoreboard`. |
| `uart_irq` | `u_uart_if.uart_irq` | Output | 1 | Passive Monitor | Monitored interrupt line signaling RX FIFO data ready (`IER[0]`) and TX FIFO empty (`IER[1]`). |
| `clk` | `u_uart_if.clk` | Input | 1 | Clock Reference | Synchronous 100 MHz AXI interconnect clock. |
| `fixed_clk` | `u_uart_if.fixed_clk` | Input | 1 | Dedicated UART Clock | 40 MHz independent baud clock (period = 25.0 ns). |
| `~rst` | `u_uart_if.rst_n` | Input | 1 | Reset Reference | Active-low reset. |

## 4. PWM VIP Connectivity Mapping

The Pulse-Width Modulation (PWM) signal is generated by the integrated 32-bit Real-Time Timer IP (`u_timer_axi`), mapped to AXI slave index S3 (`0x8000_2000 - 0x8000_2FFF`). The PWM VIP acts as a precision passive protocol monitor, measuring pulse period, high time, low time, frequency, and duty cycle.

### 4.1 Interface Signal Map (`pwm_if`)

| DUT Port (`main_top.v`) | VIP Interface Signal (`pwm_if`) | Signal Direction (DUT perspective) | Width | VIP Role | Verification Function |
| :--- | :--- | :--- | :---: | :--- | :--- |
| `timer_pwm` | `u_pwm_if.pwm_out_o` | Output | 1 | Passive Timing Monitor | Monitors PWM waveform edges (`t_rise1`, `t_fall`, `t_rise2`), computes duty cycle percentage, and checks accuracy against programmed compare value (`TIMER_CMP`). |
| `timer_irq` | `u_pwm_if.timer_irq` | Output | 1 | Passive Monitor | Monitored interrupt output asserted when timer counter reaches match or reload condition. |
| `clk` | `u_pwm_if.clk` | Input | 1 | Clock Reference | Synchronous 100 MHz AXI clock (10.0 ns resolution). |
| `~rst` | `u_pwm_if.rst_n` | Input | 1 | Reset Reference | Active-low reset. |

## 5. SoC Control & Stimulus Interface (`soc_ctrl_if`)

To enable deterministic peripheral configuration without requiring pre-compiled CPU firmware in every test scenario, `soc_ctrl_if` drives Interconnect Master Port 1 (`s01_axi`).

| DUT Port (`main_top.v`) | Control Interface Signal (`soc_ctrl_if`) | Signal Direction | Description |
| :--- | :--- | :---: | :--- |
| `s01_axi_aw*` | `u_soc_ctrl_if.aw*` | In to DUT | Single-beat AXI4 Write Address Channel |
| `s01_axi_w*` | `u_soc_ctrl_if.w*` | In to DUT | Single-beat AXI4 Write Data Channel |
| `s01_axi_b*` | `u_soc_ctrl_if.b*` | Out of DUT | Write Response Channel |
| `s01_axi_ar*` | `u_soc_ctrl_if.ar*` | In to DUT | Single-beat AXI4 Read Address Channel |
| `s01_axi_r*` | `u_soc_ctrl_if.r*` | Out of DUT | Read Data Channel |

## 6. Memory & Dummy Responder Interconnect Termination

| Slave Index | Base Address | Mapped Entity | Termination Model | Function |
| :--- | :--- | :--- | :--- | :--- |
| **S0** | `0x0004_0000` | Instruction RAM (IMEM) | `axi_ram_slave` (128 KB) | AXI4 burst-capable memory responder. |
| **S1** | `0x0008_0000` | Data RAM (DMEM) | `axi_ram_slave` (128 KB) | AXI4 burst-capable memory responder. |
| **S2** | `0x8000_1000` | GPIO Peripheral | Real RTL (`u_gpio_axi`) | Connected to `u_gpio_if`. |
| **S3** | `0x8000_2000` | Real-Time Timer / PWM | Real RTL (`u_timer_axi`) | Connected to `u_pwm_if`. |
| **S4** | `0x8000_3000` | UART Controller | Real RTL (`u_uart_axi`) | Connected to `u_uart_if`. |
| **S5** | `0x8000_0000` | AES-128 Accelerator | Real RTL (`u_aes_axi`) | Fully instantiated. |
| **S6** | `0x8000_4000` | FFT Control Registers | Real RTL (`u_fft_ctrl`) | Fully instantiated. |
| **S7** | `0x8000_5000` | FFT Data BRAM | Real RTL (`u_fft_mem`) | Fully instantiated. |
| **S8..S14** | `0x8000_6000+` | Unmapped Addresses | Internal Dummy Responders | Returns `DECERR` (2'b11) to avoid interconnect lockups. |

## 7. Summary of Preserved RTL & Non-Intrusive Integration

- **DUT RTL Unchanged:** `main_top.v` is preserved exactly in its integrated state.
- **Pin Passthrough:** Every VIP connects solely to designated external top-level ports.
- **Protocol Fidelity:** Tri-state GPIO behavior, dual-clock UART serial frames, and edge-accurate PWM timing are strictly adhered to.
