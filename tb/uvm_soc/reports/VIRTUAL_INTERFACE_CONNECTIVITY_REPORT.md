**`build_phase` VIF Retrieval:**
```systemverilog

    super.build_phase(phase);
    if (!uvm_config_db#(virtual gpio_if)::get(this, "", "gpio_vif", vif)) begin

```

**Signals Driven in `run_phase`:**

| Signal | Driven Value | Condition |
|--------|-------------|-----------|
| `vif.gpio_oe` | `32'h0` (init), then `req.gpio_oe` | Active when `GPIO_OP_DRIVE` |
| `vif.gpio_in` | `32'h0` (init), then `req.gpio_in` | Active when `GPIO_OP_DRIVE` |
| `vif.gpio_oe` | `32'h0` | Released to Hi-Z when `GPIO_OP_RELEASE` |
| `vif.gpio_in` | `32'h0` | Released when `GPIO_OP_RELEASE` |

**Supported Transactions (`gpio_op_e` enum):**
- `GPIO_OP_DRIVE` — Tri-state drive: sets `gpio_oe` and `gpio_in`, holds for `req.hold_cycles` clock edges
- `GPIO_OP_RELEASE` — Release all pins to Hi-Z (`gpio_oe = 32'h0`)
- `GPIO_OP_SAMPLE` — Idle wait (no driving); hold for `req.hold_cycles` cycles

**Physical Tri-State Mechanism:** The `gpio_oe[i] ? gpio_in[i] : 1'bz` assignment in `gpio_if` creates the actual `inout` bus behavior. The driver only sets the control registers; the interface's `generate` block performs the physical tri-state resolution.
